## 为什么忽略 `TTS/data/`

`TTS/data/` 目录包含约 **360+ 个 WAV 音频文件**（总计约 **203MB**），内容为：

- `02_all/`：VMina 角色的全部游戏语音台词（选中、部署、战斗、信赖等场景）
- `sp_ref/`：TTS 推理用的参考音频样本

这些音频文件属于以下性质，因此不纳入 Git 版本管理：

1. **体积过大**：单个仓库不应承载 200MB+ 的二进制音频，会严重拖慢 clone/pull 速度
2. **来源明确**：语音文件提取自游戏资源包，可随时重新提取，非不可再生数据
3. **频繁变动**：调整剪辑或重新录制时会产生大量 diff，对代码版本管理无意义
4. **Git LFS 替代方案**：如确需版本管理，建议使用 Git LFS 或单独的音频素材仓库

如需使用这些音频，请从原始游戏资源中提取并放入 `TTS/data/` 对应路径。
